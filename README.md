# ERA Super AI Assistant (Android Project)

## Features Included:
- **Sci-Fi HUD Dashboard:** Real-time RAM, Battery, Date & Live Clock.
- **Pulsing AI Orb:** Interactive Canvas Orb responding to listening states.
- **Shake Detection Service:** Accelerometer-based instant wake-up trigger.
- **Accessibility Automation Service:** Automatic screen tapping, swiping, typing, home/back navigation.
- **Dynamic Super Agent Spawner:** Generates tailored sub-agents on the fly (DealHunter, TravelVoyager, DocuSense, TaskSolver).
- **Female Voice Audio Engine:** Text-to-Speech & Speech Recognition.

## How to Build the APK in 2 Minutes:
1. Extract this zip file.
2. Open **Android Studio** -> Click **Open** -> Select `EraAssistantProject`.
3. Connect your Android phone via USB (or run in Emulator).
4. Click **Run** (Green Play button) or go to **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
5. In your phone settings:
   - Go to **Accessibility** -> Turn ON **ERA Assistant** (Required for auto clicks/navigation).
   - Grant **Microphone** permission when prompted.
